# mindmap — интеллект-карты, канбан и сетевой график в терминале

```bash
mindmap              # карта по умолчанию: на macOS iCloud/Карты/Карта.md, на Linux ~/Карта.md
mindmap план.md      # другой файл; если его нет, появится при первом сохранении
```

## Установка

Нужен Python 3.10 или новее и [pipx](https://pipx.pypa.io/); git не нужен — ставится из архива GitHub.

```bash
# Linux (Ubuntu/Debian)
sudo apt install pipx && pipx ensurepath          # затем открыть терминал заново
pipx install https://github.com/antiloch/mindmap/archive/refs/heads/main.zip
# macOS
brew install pipx && pipx ensurepath
pipx install https://github.com/antiloch/mindmap/archive/refs/heads/main.zip
```

Обновить — та же команда с `--force` (`pipx install --force https://…/main.zip`), удалить — `pipx uninstall mindmap`. Карта — обычный файл `.md`, программа его только читает и пишет; между компьютерами его переносит iCloud, облако или флешка.

На Linux ссылки открываются через `xdg-open`, копирование `y` идёт в буфер через `wl-copy` (Wayland), `xclip` или `xsel` — если ни одной нет, через сам терминал (OSC 52, умеют многие терминалы, в том числе по SSH). На macOS — `open` и `pbcopy`.

Главная тема в левом верхнем углу, ветки идут вправо и вниз: первый ребёнок вровень с родителем,
остальные ниже. Все блоки одной ширины, вложенность без предела. Управление с клавиатуры, как в vim;
стрелки работают наравне с `hjkl`, все клавиши — и в русской раскладке. Вкладки — `Shift+←` и `Shift+→`
или `gT` и `gt`. `v` переключает виды по кругу: карта → канбан → сетевой график → карта. Полный список — по `?` внутри программы. Выход — `:q`.

## Статусы

`Space` по кругу: нет статуса → не завершено (`☐`) → завершено (`☑`, серый) → провалено (`✗`, тёмно-красный) → не завершено. «Провалено» — задача закрыта неудачно: её срок больше не горит красным, с канбана она уходит, на графике тёмно-красная. Счётчик `1/3` на рамке родителя считает удачно завершённых из всех детей со статусом.

## Завершённые пункты

На карте завершённые и проваленные пункты спрятаны вместе с ветками. Первым ребёнком родителя стоит серое окошко `… завершено: 2✓ 1✗`. На него встаёт курсор, `za` или `zo` показывает их на своих местах, `za` или `zc` прячет снова. Пункт, который только что закрыли, уходит за «…», и курсор встаёт на окошко. Исключение — задача с неоценёнными критериями: она остаётся на виду, а внизу появляется «Оцените критерии и разбор: gk».

Показанное помнится до выхода из программы, в том числе после отмены `u`; файл не меняется. `zM` и `zR` завершённые не трогают. На «…» правка не действует (`i`, `Space`, `dd` и т. п.), выделение `c` его пропускает, а спрятавшиеся отметки снимаются. `J`/`K` и `L` считают соседями только видимые пункты. Переход по ссылке на пункт и `Enter` с канбана или графика показывают спрятанный пункт.

## Выделение и команды сразу на несколько пунктов

`c` включает выделение, стрелки добавляют пункты, шаг назад снимает последний, `Esc` выходит. Зажатая вместе со стрелками `c` работает так же: режим не выключается повторным нажатием. Терминал не сообщает программе об удержании буквы, поэтому это режим, а не сочетание.

Команды действуют на все отмеченные пункты, их дети не меняются. После команды выделение остаётся, чтобы сразу применить следующую.

| Клавиша | Что делает |
|---|---|
| `Space` | пункт под курсором получает следующий статус, остальные — такой же |
| `S` | убирает статус |
| `t` | ставит срок: в поле общий срок, если он у всех одинаковый; пустой ввод снимает |
| `1`–`4` | ставит приоритет; если у пункта под курсором он уже такой — снимает у всех |
| `za` `zc` `zo` | сворачивает или разворачивает; отметки внутри свёрнутого снимаются |
| `gl` | добавляет всем одну ссылку, без дублей |
| `dd` | вырезает с ветками после подтверждения и выходит; главная тема остаётся |
| `y` | копирует с ветками и выходит |
| `u` | отменяет последнее и выходит |

Весь набор — один шаг отмены, кроме свёртывания: оно в отмену не входит, как и у одного пункта.

## Копирование

Каждый выделенный пункт копируется со всей веткой, дубли и порядок разбираются сами. `p` вставляет скопированное дочерним к выбранному пункту одним шагом отмены. `y` и `yy` кладут текст Markdown ещё и в системный буфер (Cmd+V в другой программе); `dd` буфер macOS не трогает.

## Приоритеты

`1` — `▰▰▰▰` (самый важный), `2` — `▰▰▰`, `3` — `▰▰`, `4` — `▰`; та же цифра снимает. Полоски можно набрать и в окне названия. На канбане внутри раздела сверху самые важные, пункты без приоритета в конце, при равном приоритете порядок по дате.

## Критерии успеха и разбор (`gk`)

По Фридману цель без критериев не оценить. `gk` на карте, канбане и графике открывает окно критериев пункта.

- `a` — добавить критерий и необязательный факт (`Tab` — между полями), `Enter` — изменить, `d` — удалить, `J`/`K` — порядок.
- `Space` — оценка: `○` не оценён → `✓` достигнут → `✗` не достигнут.
- `r` — разбор итога: цифрой вид (`1` закономерный успех, `2` «чудо», `3` форсаж, `4` провал; у проваленной задачи заранее выбран провал), затем причина и что меняем в системе управления. В окне выбора `d` убирает разбор.
- `Esc` сохраняет; всё, что сделано в окне, — один шаг отмены `u`.

У пункта с критериями или разбором на верхней рамке стоит `◎`. Когда `Space` закрывает задачу, а критерии не оценены или нет разбора, программа напоминает об этом внизу.

## Заметки

`n` на карте, канбане и графике открывает заметку пункта: текст в несколько строк, `Enter` — новая строка, `Esc` — сохранить и закрыть (не зависит от раскладки; лишнее отменяет `u`). У пункта с заметкой на верхней рамке стоит `✎`, сам текст в окошке не показывается. Пустая заметка удаляется, ссылки пункта при правке не теряются.

## Ссылки

У пункта может быть несколько ссылок, в окошке они показаны строкой под датами.

- `Enter` на карте или `gx` в любом виде: одна ссылка открывается сразу, при нескольких появляется список, цифра открывает нужную.
- `gl` — добавить. `gL` — список: открыть или удалить (`d`).

| Что ввести в `gl` | Что откроется |
|---|---|
| `https://…`, `www.…`, `mailto:…` | страница или письмо в программе по умолчанию |
| `/…`, `~/…`, `./…`, `../…`, `file://…` | файл или папка в программе по умолчанию; относительный путь — от папки карты; файл можно перетащить в поле |
| часть названия пункта | переход на пункт, в том числе на другую вкладку; при нескольких совпадениях окно просит уточнить |

Программы и скрипты (`.app`, `.command`, `.sh`, `.tool`, `.terminal`, `.workflow`, `.pkg`, `.mpkg` и исполняемые файлы) запускаются только после подтверждения. Прочие адреса (например `xmind:#…`) программа показывает, но не открывает.

Ссылка на пункт хранит его название. Переименование через `i` обновляет ссылки, если других пунктов с прежним названием нет; при нескольких одинаковых названиях ведёт на первый найденный, кроме самого пункта со ссылкой.

## Мышь

Клики ничего не делают. Колёсико прокручивает карту (Shift+колёсико — вбок), на канбане двигает выбор карточки. Программа сама принимает колёсико: иначе Terminal.app прокручивал бы свою историю над её экраном. Поэтому выделить текст на экране мышью можно только с зажатым `Option`. В меню Terminal «Вид» должна быть включена «Разрешить отчёты о мыши», по умолчанию так и есть.

## Формат файла

Обычный Markdown, можно править руками, открытая программа перечитает файл сама.

```markdown
# Работа

- Пункт без статуса и даты
  - [ ] Не завершено @2026-11-02..2026-11-06
  - [x] ▰▰▰▰ Завершено, самый важный @2026
  - [-] Провалено @2026-11-01
- Свёрнутая ветка <!--collapsed-->
  - скрытый пункт
- Пункт с критериями
  Критерий: [x] написали ≥ 90 % детей → 94 %
  Критерий: [-] средний балл ≥ 15 → 13,4
  Разбор: провал
  Причина: пробник поставили на неделю олимпиад
  Меняем: пробники только по графику ВСОКО
- Пункт со ссылками
  Ссылка: https://thecode.media/launchctl/
  Ссылка: ~/Desktop/отчёт.pdf
  Ссылка на пункт: Свёрнутая ветка

# Личное
```

- `#` — вкладка и главная тема. Пункты — элементы списка, вложенность — отступом.
- Статус, приоритет и срок необязательны. Срок — `@НАЧАЛО[..КОНЕЦ]` в конце строки, точность `ГГГГ`, `ГГГГ-ММ`, `ГГГГ-ММ-ДД`, `ГГГГ-ММ-ДДTЧЧ:ММ`.
- Приоритет — полоски `▰▰▰▰`…`▰` сразу после статуса. Значки `❶–❹` от прежних файлов читаются и при первом сохранении заменяются полосками.
- Статус: `[ ]` не завершено, `[x]` завершено, `[-]` провалено. Так же отмечаются критерии: не оценён, достигнут, не достигнут; факт — после ` → `.
- Строки с отступом без маркера — заметка пункта (`n`). Строки `Ссылка: …` и `Ссылка на пункт: …` — ссылки, `Критерий:`, `Разбор:`, `Причина:`, `Меняем:` — критерии и разбор (`gk`). Строку заметки, похожую на пункт, вкладку, начало блока кода или служебную строку, программа пишет с `\` впереди, чтобы файл не прочёл её иначе.

## Даты на экране

Как бы срок ни ввели (`завтра`, `пт`, `5.11`, `2026-11-05`), на карте, на канбане и в окне срока вид один: `2026`, `11.2026`, `05.11.2026`, `05.11.2026 15:20`; у периода оба края полностью: `05.11.2026 – 07.11.2026`.

## Цвета

Неделя — понедельник–воскресенье. Срабатывает первое подошедшее правило.

1. Завершено — серый («полупрозрачный»), провалено — тёмно-красный, так же приглушённый.
2. Нет даты — обычный.
3. Конец срока прошёл — красный, в том числе у пункта без статуса.
4. Уже идёт — начался и кончается позже этой недели — жёлтый (годовая цель `2026` жёлтая весь год).
5. Период задевает текущую неделю — оранжевый: срок на этой неделе или начало позже на этой неделе.
6. Начало на следующей неделе (любой длины) — зелёный.
7. Остальное — обычный.

Легенда внизу: просрочено, идёт, неделя, след., завершено, провал.

Статус родителя и детей независимы, счётчик `1/3` на рамке только показывает прогресс.

## Канбан (`v`)

На доске только незакрытые пункты с датой; колонки вычисляются из даты и статуса. Завершённых и проваленных на доске нет: смотреть на них незачем, итог разбирают по `gk`, а видны они на карте (`za`) и на графике.

- **Запланировано** — будущее, два раздела: «Следующая неделя» (всё, что начинается на следующей неделе) и «Позже»; в обоих сверху самые важные, без приоритета — в конце, при равном приоритете — по дате.
- **На этой неделе** — разделы «Сегодня», «Просрочено», «Эта неделя», «Идёт» (уже начался и кончается позже этой недели, жёлтый).

Карточка рисуется внутри карточки родителя, если она из той же ветки и того же раздела доски, а весь её срок лежит внутри срока родителя (совпадающий срок тоже считается). Выбор ходит по всем карточкам, вложенным тоже, родитель идёт перед своими. Когда выбран родитель, подсвечена вся карточка с вложенными, но команды действуют только на него. В строке «откуда» у вложенной карточки только путь от родителя. Подзадача из другого раздела остаётся там, чтобы «Сегодня» и «Просрочено» не прятались внутри «Идёт». Если колонка слишком узкая для ещё одного уровня, вложенные идут сразу под родителем.

`H`/`L` двигают карточку между колонками через окно даты; `L` из недели завершает задачу. Закрытая (`L` или `Space`) карточка уходит с доски, выбор встаёт на соседнюю, внизу «Завершено: … · u — вернуть». Если у задачи есть неоценённые критерии или нет разбора, сразу открывается окно `gk`: потом его было бы не на чем нажать. «Провалено» ставится на карте или графике. `a` — текущая вкладка или все, `Enter` — открыть пункт на карте.

## Сетевой график (`v` с канбана)

`-` отдаляет, `+` (или `=`) приближает: неделя → месяц → квартал → год. Период виден справа в строке вкладок («график · квартал») и помнится до выхода.

| Период | Окно при включении и по `0` | Столбец | `h`/`l`, `←`/`→` |
|---|---|---|---|
| неделя | 7 дней с сегодня | день | на день |
| месяц | календарный месяц | неделя (пн–вс, крайние неполные) | на неделю |
| квартал | календарный квартал | неделя | на неделю |
| год | календарный год | месяц | на месяц |

При сдвиге длина окна постоянна (7 дней, 5 недель, 13 недель, 12 месяцев); сдвинутое окно месяца и квартала начинается с понедельника. При смене масштаба окно строится вокруг сегодня, если оно было видно, иначе вокруг начала окна. Выбранная однодневная задача, которую скрыл крупный масштаб, снова выбрана при возврате к неделе.

На графике пункты, чей срок задевает окно, завершённые — серым, проваленные — тёмно-красным. Порядок как на канбане: приоритет, потом дата.

### Задачи строками (все периоды)

Каждая задача — полоса в одну строку, как в диаграмме Ганта: `╺━━━╸` длиной ровно в свои дни (x считается по дням, не по столбцам: трёхдневная задача на квартале — короткая полоса). Так рисуется и неделя: на экран входит втрое больше задач, чем окошками.

- Название — на полосе, если влезает; иначе справа от неё, у правого края — слева, совсем без места — поверх полосы. В названии статус, приоритет, на неделе — время начала (если оно в окне), затем `✎ ◎`.
- Срок дальше окна — `‹`/`›` на конце полосы; годовая цель — полоса во всю ширину. Выбранная задача — подсвечена вся строка.
- Подзадача рисуется внутри ближайшего предка с графика, если её дни лежат внутри его дней в этом окне: родитель — рамка на свои дни, дети внутри полосами. Рамка уже 24 символов — дети идут под ней: внутри не было бы видно названий.
- Каждая задача на своей строке, рядом ничего не ставится. `j`/`k` ходят в порядке экрана. Выбор подсвечивает и вложенные, команды (`Space S t i 1-4 gx gl gL u`) действуют только на выбранную. `a` — текущая вкладка или все, `Enter` — открыть на карте.

### Только на месяце, квартале и годе

- **Однодневные задачи не рисуются.** Их число (все, включая закрытые) стоит в черте под заголовком посередине своего столбца — так видны перегруженные недели и месяцы. Исключение — **вехи**: однодневная задача с приоритетом `▰▰▰▰` или `▰▰▰` рисуется `◆ название` в свой день и выбирается `j`/`k`. На неделе однодневная задача — без полосы, просто надпись с начала своего дня (длинная идёт вправо, у правого края обрезается, полное название — в строке внизу при выборе).
- Заголовки: месяц и квартал — дата начала недели (`02.11`), год — `янв`…`дек` (у первого столбца и января — с годом, если влезает). Неполную неделю у края не подписываем.

## Сохранение

Автоматически после каждого действия, атомарно. Открытие файла его не переписывает: неровный файл, написанный руками, приводится к единому виду только при первой правке. Если файл поменяли извне в момент записи, чужая версия остаётся рядом как `<имя>.conflict-<время>`. Файл, выгруженный iCloud, сначала скачивается, чтобы пустая карта не затёрла настоящую. Отмена `u` — 100 шагов, на время сеанса.

## Разработка

```bash
cd tools/mindmap
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest pytest-asyncio
.venv/bin/python -m pytest -q
```

**Грабли.** Pilot не ловит всё: последовательности `Shift+стрелок` и колёсика, отчёт о мыши, настоящие `pbcopy` и `open` проверять прогоном `mindmap` в псевдотерминале, а `pbcopy` и `open` подменять заглушками в `PATH`, иначе тест затрёт буфер и откроет браузер. Первый запуск только что созданной заглушки занимает заметное время, поэтому результат ждать, а не считать сбоем сразу. Символы `▰`, `≥` и подобные через `pilot.press` не вводятся: в тесте значение поля задавать напрямую. Клавиши `-`, `+`, `=` в `pilot.press` — это `minus`, `plus`, `equals_sign`. Скрипт прогона в псевдотерминале не называть `pty.py`: он перекрывает стандартный модуль. После закрытия задачи курсор уже стоит на «…»: всё, что зависит от пункта под курсором, запоминать до смены статуса. Активная вкладка отличается только оформлением: проверять по нижней строке, а не по тексту шапки. Имена атрибутов виджетов сталкиваются с Textual (`App.clipboard`, `ScrollView.tree`). При `AUTO_FOCUS = ""` у приложения окнам с полем ввода нужен свой `AUTO_FOCUS = "Input"`, иначе ввод никуда не идёт.
